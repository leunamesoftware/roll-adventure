# Referência Visual do Jogo

> Estas imagens/descrições são referências de estrutura e estilo, não artes finais.
> Nenhum personagem, cenário, inimigo, obstáculo, som, animação ou interface final deve copiar
> as referências — apenas a organização de telas e o nível de qualidade esperado são reaproveitados.
> Toda arte final é original.

## Telas do jogo

| # | Tela | Conteúdo principal |
|---|------|---------------------|
| 1 | Tela Inicial / Menu | Logo, personagem, Jogar, Personagens, Mundos, Conquistas, Configurações, moedas/recursos |
| 2 | Seleção de Mundos | Lista de mundos, estrelas, bloqueio, navegação |
| 3 | Gameplay (fase) | Inimigos terrestres/voadores/especiais, obstáculos, coletáveis, HUD (vidas, moedas, tempo, poder, pausa), controles (esquerda/direita/pular/poder) |
| 4 | Personagens | Trixo (principal) + skins originais desbloqueáveis |
| 5 | Loja | Moedas, vidas, escudos, ímãs, poderes, skins — opcional, sem obrigar compra; recompensa por anúncio voluntário |
| 6 | Mapa de Fases | Progresso por fase, estrelas, fases bloqueadas, chefe do mundo |
| 7 | Vitória | Estrelas, moedas, tempo, pontuação, recompensas, próxima fase/repetir/menu |
| 8 | Derrota | Tentar novamente / voltar ao mapa — sem anúncio obrigatório |
| 9 | Conquistas e Ranking | Conquistas com progresso, ranking (pontuação, tempo, fases), preparado para modo online |
| 10 | Novos Mundos | Vitrine de mundos futuros — arquitetura já preparada para crescer |

## Sistema de crescimento contínuo

Arquitetura modular para permitir, via atualização e sem reconstruir o jogo:
novas fases, novos inimigos, novos obstáculos, novos poderes, novos personagens, novos mundos, eventos.
Ver `docs/ARQUITETURA.md`.
